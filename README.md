# Atharva Raju Kale — Portfolio

A responsive, single-page personal portfolio built with HTML, CSS and a little JavaScript.

## Deploy with GitHub Pages

1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. GitHub Pages will publish the site at:
   https://akale2715-admin.github.io/atharva-portfolio/

## Custom domain

When the domain `atharvakale.in` is registered and ready:
1. Enter `atharvakale.in` in **Settings → Pages → Custom domain** and save.
2. Configure the DNS records at your domain registrar as instructed by GitHub Pages.
3. Once DNS is verified, enable **Enforce HTTPS**.
